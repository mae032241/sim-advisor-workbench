# MPH 资料提取

模型库共用保存状态读取与可选 COMSOL Deep API 读取流程，官方/自定义分类是资料库登记声明。源码发布不附原始 MPH、官方教程、解析结果或依赖二进制。

## 离线 compact 路径

当前资料库构建默认使用 compact 格式，将保存的节点、类型化设置和证据定位去重存入不可变资料版本；检索目录保留限长文本与行引用，完整值按需读取。原始 XML 证据从哈希匹配的来源 MPH 按需读取，不把展开后的大份保存状态作为常驻副本。原始来源离线或不匹配时，证据读取明确报告不可用。

离线提取不启动 COMSOL。保存节点、选择编码、默认值或表达式只是保存状态证据，不能证明有效启用、当前几何成员、物理适用性、网格质量或求解结果时效性。`legacy` 格式兼容旧资料，不能据旧格式推定当前缓存与存储布局。

## 可选 Deep API

Deep API 需要用户自备可用的 COMSOL 安装和 Java 运行环境。`ReadMph.java` 或批量 getter 在独立进程中读取工作副本，枚举已保存配置与选择；不执行几何、网格、默认求解器生成或求解。

API 观测与离线底稿分别保留。已有 compact 库可通过 [enrich_model_api.py](../enrich_model_api.py) 显式增量增强；其 checkpoint 支持状态查询、取消与继续。差异、缺失、getter 失败与仅预览模型保持明确状态，不用教程描述或其它模型替代失败读取。

`partial` 表示读取存在未核实部分；读取成功也不等于所有有效设置、外部模型数据依赖和数值结果已验证。导出的 Java 是重建来源，代码分段及依赖仅为阅读线索，未证明片段可独立执行。

## 原始文件与派生数据

原始 MPH 只读使用，并检查内容指纹及文件状态的一致性。复制件、临时 Java 类及构建中间文件按对应流程清理，必要证据与资料版本保存在工作台数据目录；无法清理时返回警告，不能静默声称清理完成。私有运行目录不进入公开源码。

教程关联仅是带版本和来源的引用，不能证明教程设置与用户模型一致。正文由登记文档库按其可见性读取。配置、代码与原始 XML 证据须使用各自引用和读取接口核对。

实现见 [compact_model.py](../../advisor/compact_model.py)、[compact_library.py](../../advisor/compact_library.py)、[library_model.py](../../advisor/library_model.py) 与 [ReadMph.java](ReadMph.java)。入口参数以 `python library_cli.py --help` 和相关脚本的 `--help` 为准。
