# 纯几何规划工具

本目录保留几何输入准备代码，用于将自备模型的几何与私有仿真设置分开，构造规划评测输入。源码发布不附原始模型、固定 scenario/rubric、官方 benchmark 资料或既有准备与评测结果。

## 自备输入

`prepare.py` 接收 `--source <模型路径>` 和可选 `--output-root <输出目录>`，在隔离副本中准备几何。它需要用户自备 COMSOL 和几何解析依赖；请先核对源码中的安装位置配置与执行范围。

该专用准备流程会构建几何、导出中性 CAD，并建立不含物理场、材料、网格、研究、求解器和解数据的新模型。它不运行网格或求解。准备报告检查原始文件未变、元数据中性化和几何交换一致性，不证明 CAD 有效、可网格化、无重叠或物理适用。

原始身份、参考设置、来源哈希及中间资料保留在私有侧。向规划 Agent 提供输入前，应自行复核中性文件和报告，不把原始模型、教程或私有评分材料加入上下文。

## 运行规划

先准备自备 scenario JSON；运行入口通过 `--scenario` 显式提供，不依赖仓库内置题目：

```powershell
python scripts/run_geometry_challenge.py --help
python scripts/run_geometry_challenge.py --geometry "<中性STEP路径>" --scenario "<自备scenario.json>" --output-root "<本次输出目录>"
```

scenario 至少需提供 `public_goal`，结构以运行脚本为准。默认仅创建与检查输入，`--plan` 才请求真实规划。该入口仍需配置适用的检索范围和后端；开始模型调用前核对代码及依赖。不要把缺省参数视为可直接复现的公开基线。

benchmark CLI 的输入也由用户构造，并通过 `--root <自备benchmark根目录>` 提供；目录、清单和评分文件必须满足相应源码校验。测试集隔离配置使用自备 `--selection`，详见 [测试集隔离](../../docs/evaluation-sets.md)。

准备、规划质量和数值验证是不同检查。几何实体数、距离及边界框不能指定材料、接触、密封角色、流体域或边界条件；规划成功也不表示求解或工程验收已经完成。
