# 原生 HTML 功能手册树

0.2.64 将原生 HTML 章节树接入资料库和共享规划流程。它从已有功能手册的 `toc.xml` 派生父子、同级及祖先标题，保留原始 HTML 页、锚点和文件指纹。索引不存正文副本，不调用模型、COMSOL、embedding，也不重建 QMD。

## 研究顺序

明确需求与资料库范围后，优先用 `get_html_navigation` 定位父接口与候选方法，再用 `read_html_section` 核对适用条件、假设和关键量传递。不同接口可能有同名特征，应连同祖先标题判断，不能只按叶节点标题套设置。

QMD 继续用于术语、表达式、实现代码与相近案例搜索，也可帮助定位手册。其命中 `source_id` 可反查原生树。树未准备、没有原生 HTML 对应项或较早客户端未提供树工具时，继续用既有 `search_knowledge` 与 `read_source`，不据此推断没有相关方法。

按任务需要查看父接口、子章节、同级和相邻说明；不要求遍历整本手册或固定读取次数。比较候选方法保留的现象、成立与失效条件，核对关键量的产生方、接收方、作用域、定义与传递方向。导航标题本身不授予正文阅读权限。

## 构建与已有库补建

先登记自己有权使用的 HTML 功能手册根目录。支持原生目录的手册库在正常资料构建发布后生成或刷新章节树，由资料库管理；无需每次启动或读取时重新构造。没有原生目录的手册和 PDF 继续使用 QMD，不要求安装 PageIndex SDK。

已有资料库可在网页资料库详情的“手册章节导航”中查看计数，点击“补建章节树”；后台任务可查看进度或取消。也可只补建树：

```powershell
python library_cli.py --data-dir <工作台数据目录> build-tree <资料库ID>
```

该入口只处理目录元数据，不重新解析模型或正文、不重做 QMD、不启用资料库，也不创建向量。实际原始资料仍位于登记目录。移除、关闭或删除库后，读取继续遵守其当前状态，不因已有树节点而放宽范围。

需要独立目录导出或离线调试时，仍可显式运行：

```powershell
python scripts/build_html_tree.py --html-root <已登记的HTML根目录> --output <新的章节树目录> --library-id <资料库ID> --root-id <HTML根ID>
```

此脚本不覆盖已有输出，也不自动登记或启用库。`SIM_ADVISOR_HTML_TREE_INDEX` 保留为单树兼容入口，可指向目录或其中的 `index.sqlite3`；正式使用由资料库树注册表发现可用树，无需固定本机路径。

## 同源工具

托管 Codex/DSH、外部会话、HTTP、CLI 与 MCP 从共享 `PlanningService` 发现工具和契约，使用同一研究规范。

- `get_html_navigation`：浏览手册包或章节；`node_id` 展开节点，`query` 在标题及祖先中筛选。`source_id` 将已有 QMD 引用映射回原始 HTML 节点，与 `node_id` 互斥。多树入口可按当前 schema 提供的 `tree_id` 限定范围。
- `read_html_section`：使用返回的精确 `node_id` 读取 HTML 页或锚点正文，同时返回祖先、父节点、同级及相邻阅读入口。

节点 ID 作为不透明身份复制使用，不拼路径、不自行构造。导航每页最多 8 项；正文默认请求 1800 字符，最多 3200 字符。每个回包最多 7000 UTF-8 字节；若可容纳的正文较少，会返回真实字符范围与 `next_offset`，按该游标继续。

`next_offset=null` 只表示当前页或锚点正文已结束，不代表整章或相邻章节已读。图片、公式图和外链保留明确引用；文本工具不进行 OCR，也不能把未转录图片猜成公式。

## 引用与权限

在当前方案中实际调用 `read_html_section` 后，返回的来源身份与精确 `html_section` 范围进入阅读账本。方案和设置表可直接引用该 `source_id` 与服务生成的 `evidence_refs`，不必为登记引用再做一次 QMD 读取。独立于方案的读取不会自动成为某个方案的已读记录。

HTML 原文、`source_text`、保存配置与 API 观察是不同证据范围。原文件指纹、锚点及文本范围必须保持原样；节点标题、搜索命中或其他章节不能代替本节正文。实际读取不证明表达式抄录正确、方法适用、配置生效或求解完成。

每次读取仍检查库启用/删除状态、登记根、原始文件指纹及隔离范围；旧节点 ID 不能绕过关闭或隔离。根目录迁移使用既有重关联流程，内容改变时按状态提示刷新树。功能手册树排除模型实例教程和 addins，不因升级开放其原有访问边界。

## 案例与升级

案例先用 `search_cases` 发现并读取概览，再通过 `get_case_navigation` 逐层查看已解析节点、依赖和手册关联；`get_case_guide` 保留摘要，原值仍由 `read_case_configuration` 读取。案例树与功能手册目录语义不同，不将每个模型节点当作手册章节，也不把原生层级当作物理因果图。0.2.65 的脚本只从既有结构化档案派生元数据，不重新解析案例，见 [案例树导航](case-tree-navigation.md)。

升级插件后重启工作台；外部 DSH 会话重新绑定以登记当前工具和共享提示。旧离线依赖包可以继续使用，不新增 Python 第三方依赖、模型权重或默认 embedding。源码和插件不附官方手册、用户模型、章节树数据或本地会话。
